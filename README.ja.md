# zing-explore

[繁體中文](README.md) | [English](README.en.md) | 日本語

軽量・高速・カスタマイズ可能な Windows 11 用ファイルマネージャー（実行ファイル `zing.exe`）。Rust + Win32 + Direct2D、実行ファイルは約 1 MB。

## ビルドと実行

Rust（MSVC ツールチェーン）と Visual Studio Build Tools（C++ と Windows SDK）が必要です。

```powershell
cargo build --release
.\target\release\zing.exe
```

`cargo build --release` で `zing-index.exe`（NTFS インデックス サービス。下の「フォルダーのサイズ」を参照）も同時にビルドされます。

## 現在の機能（MVP）

- 単一ペイン + ツリー。複数のペインに分割でき（`Ctrl+\`）、各ペインにタブがある（`Ctrl+T`）
- 詳細一覧：名前／更新日時／種類／サイズ。列見出しのクリックで並べ替え、列の境界のドラッグで幅を調整。フォルダーごとに並べ替え方を記憶
- 文字を入力するとすぐに絞り込み（`*.rs` のようなワイルドカード可。IME の変換ウィンドウはフィルターのラベルに合わせて表示）、`Esc` で解除
- 全ドライブ検索（`Ctrl+F`）：ローカルのすべての NTFS ドライブを名前やパスですぐに検索し、種類・サイズ・更新日時で絞り込み、並べ替えができる（NTFS インデックス サービスが必要。下の「フォルダーのサイズと全ドライブ検索」を参照）。
  複数の語は空白で区切る（すべて一致する必要がある）。`*` `?` ワイルドカード、空白を含む語は `"…"` で囲む。`Enter` で項目のあるフォルダーへ移動して選択、`Ctrl+Enter` で開く
- パンくずリストのアドレスバー（`Ctrl+L` でパスを直接入力）
- コピー／切り取り／貼り付け（エクスプローラーと相互に利用可）、ごみ箱への削除、名前の変更（`F2`）、新しいフォルダー（`Ctrl+Shift+N`）
- 名前の一括変更（複数選択して `F2`）：検索と置換（文字列または正規表現。`$1` でグループを参照、`\w`、`\d`、`\p{Han}` は漢字にも対応）、範囲（拡張子を除いた名前／拡張子／名前全体）、
  連番 `{n}`、`{n:3}`（ゼロ埋め）、`{n:3:10}`（10 から開始、一致した項目だけ数える）、大文字小文字の変換。すぐにプレビューされ、衝突
  （同じ名前、使えない文字、予約名）が示され、衝突があると実行できない。新旧の名前が重なる場合（例：01→02、02→03）は自動で一時的な名前を経由する
- システムの右クリックメニュー（サードパーティの拡張機能を含む。Shift+F10／メニューキーでも開ける）、ドラッグ アンド ドロップの出し入れ
- システムのファイルアイコン（バックグラウンドで読み込み、実行ファイルとショートカットはそれぞれのアイコン）
- プレビューウィンドウ（`Alt+P`）：テキストファイル（UTF-8／UTF-16／Big5 を自動判定）、PDF・Office・動画などは Windows のプレビュー ハンドラーで表示
  （エクスプローラーと同じ。ない場合や応答しない場合は大きなサムネイル）、画像のサムネイル、フォルダーの項目数。
  下にはエクスプローラーの詳細ウィンドウと同じプロパティを表示。幅はドラッグで調整できる
- サムネイル表示：`Ctrl+Shift+1`–`4` で一覧／小／中／大サムネイルを切り替え、`Ctrl+ホイール` で連続調整（48–256 px）。フォルダーごとに記憶。
  サムネイルは Windows から取得（エクスプローラーと同じなので、インストール済みのサムネイル ハンドラーがすべて使える）。フォルダー内に `folder.jpg/png` か `cover.jpg/png`
  があればフォルダーのサムネイルにする。設定ファイルの `[[thumbnailer]]` で外部コマンドによるサムネイル生成も指定できる（下の「カスタマイズ」を参照）。
  ファイルやフォルダーごとに、右クリックメニューの「サムネイルを設定…」で好きな画像を指定できる（名前の変更や同じボリューム内での移動後も有効。「カスタムサムネイルを削除」で元に戻る）
- お気に入り：`Ctrl+D` か右クリックの「お気に入りに追加」、ツリーの右クリックで削除。ツリーで `Ctrl+↑`／`Ctrl+↓` か右クリックの「上へ／下へ」で順序を変更
  （順序は `session.toml` に保存。設定ファイルのお気に入りも並べ替えられる）
- フォルダーの内容が変わると自動で更新
- 3 種類の組み込みスタイル（それぞれダーク／ライトがあり、システムに従うこともできる）：コンパクト（既定。高密度、角は直角、フルパス）、Fluent（ゆったり、角丸）、
  中間（Fluent の外観、中程度の密度）。コマンドパレットの「テーマ：…」で切り替え、`Ctrl+Shift+T` はスタイルを保ったままダーク／ライトを切り替え。カスタムテーマファイルも読み込める
- 設定ページ（`Ctrl+,`）：表示言語、テーマ、ツリーとコマンドパレットの位置、隠しファイルの表示、起動時のフォルダー、フォルダーのサイズなどよく使う設定。
  変更はすぐに反映され、`config.toml` の該当行に書き戻される（ファイルのコメントや並びは保持）。ショートカットキー、テーマのエディター、設定ファイルもここから開ける
- ショートカットキーとツールバーのボタンはすべて設定ファイルで定義し、コマンドには変数が使える（`{sel}`、`{dest}`、`{path}`…。`{ask:質問}` は実行時に入力を求める）
- ショートカットキーのエディター（コマンドパレットの「ショートカットキーを編集」）：コマンドを絞り込み、`Enter` を押してから新しいキーの組み合わせを押すと割り当てられる（使用中のキーは元のコマンドから外れる）。
  `Ctrl+Delete` で削除、`Ctrl+R` で既定に戻す。結果は `zing.exe` の隣の `keys.toml` に保存（`config.toml` より優先され、設定ファイルは書き換えない）
- 表示言語：繁体字中国語、英語、日本語。既定では Windows の表示言語に従い、設定ファイルで `language = "ja"` のように指定できる（`auto`／`zh-TW`／`en`／`ja`）
- フォルダーのサイズ：フォルダーに入るとすべてのサブフォルダーのサイズを表示し、サイズ順に並べ替えられる（下の「フォルダーのサイズ」を参照）
- ツリー：見えているノードはバックグラウンドでサブフォルダーを読み込むので、クリックする前に展開できるかどうかが分かる（サブフォルダーがなければ矢印を表示しない）。
  クリックするとすぐに展開。ネットワークドライブや USB メモリは事前に読み込まず、常に矢印を表示。展開中のフォルダーは、ほかの場所でサブフォルダーが追加・削除・名前変更されると自動で更新
- ファイル操作のキュー（`Ctrl+J`）：コピー／移動／削除を順に実行し、進行状況・速度（MB/s）・残り時間を表示。一時停止やキャンセルができる。名前の変更など小さな操作はキューで待たない
- コマンドパレット（`Ctrl+Shift+P`）：すべてのコマンドをあいまい検索（タイトルやコマンド名、例：`tog hid`）。ショートカットキーを表示し、最近使ったものが先頭。`>` で始めるとコマンドスクリプトを直接実行、`=` で始めると Lua の式を評価
- Lua スクリプト：`scripts\*.lua` のグローバル関数がコマンドになる（下の「Lua スクリプト」を参照）

## カスタマイズ

設定ファイル：`zing.exe` の隣の `config.toml`（`Ctrl+,` で設定ページを開く。設定ページやコマンドパレットの「設定ファイルを編集」でメモ帳で開き、`Ctrl+Shift+R` で再読み込み）。設定、テーマ、セッションはすべてプログラムのフォルダーに置かれるので（ポータブル）、
Windows の再インストールや PC の移行時はプログラムと一緒にコピーするだけです。一般ユーザーが書き込める場所に置いてください（Program Files は不可）。
テンプレートは [`crates/zing-core/src/default_config.ja.toml`](crates/zing-core/src/default_config.ja.toml) を参照してください。

```toml
language = "auto"       # auto（Windows に従う）| zh-TW | en | ja
theme = "system"        # system | dark | light（コンパクト）、fluent | balanced（システムに従う）、fluent-dark…、カスタムテーマの名前

[[key]]
key = "F6"
cmd = "copy --move --to={dest}"

[[button]]
label = "VS Code で開く"
cmd = "run code {sel}"
```

`run` でコンソールプログラム（`.bat`、`.cmd` を含む）を実行するとコンソールウィンドウは表示されず、ウィンドウのあるプログラムは通常どおり表示されます。対話型のターミナルを開くには `--console` を付けます。
例：`run --console pwsh`。

`{ask:質問}` は実行前に入力欄を表示し、答えを代入します（同じ質問は 1 回だけ。`Esc` でコマンド全体をキャンセル）。例：
`cmd = "run git commit -m {ask:コミットメッセージ}"`。

カスタムのサムネイル生成：ファイル名が `match` に一致するファイルは、コマンドが作った PNG を使います（`{in}` 元ファイル、`{out}` 出力、`{size}` 一辺の長さ）。
結果は `%LOCALAPPDATA%\zing-explore\thumbs` にキャッシュされ、ファイルが変わると作り直されます。コマンドの実行は最長 10 秒です。

```toml
[[thumbnailer]]
match = "*.stl;*.3mf"
cmd = 'stl-thumb -s {size} "{in}" "{out}"'
```

## Lua スクリプト

スクリプトは `zing.exe` の隣の `scripts\*.lua`（Lua 5.4）に置き、起動後にバックグラウンドで読み込まれます。コマンドパレットの「Lua スクリプトを再読み込み」で読み込み直せます。
グローバル関数がコマンドになり、上の `---` コメントがコマンドパレットに表示されるタイトルです。`on_navigate(path)`、`thumbnail(path)` はイベントです。
組み込みコマンドはそのまま呼べ（`nav.refresh()`、`copy(sel(), { to = "D:\\バックアップ" })`）、リストは `|` で遅延処理の段階をつなげられます：

```lua
--- 選択した画像を「画像」フォルダーに移動
function move_images()
  local imgs = sel() | filter(function(p) return path.ext(p) == "jpg" or path.ext(p) == "png" end) | list
  if #imgs == 0 then return msg("画像が選択されていません") end
  copy(imgs, { to = path.join(cwd(), "画像"), move = true })
end
```

- 実行ごとに CPU 時間の上限がある（コマンド 30 秒、サムネイルの規則 0.3 秒。入力や外部プログラムの待ち時間は含まない）。スクリプトはバックグラウンドで実行され、ウィンドウが固まることはない
- `pick_folder()` はフォルダーを選ぶダイアログを表示。`run{ ..., wait = true }`、`os.execute`、`io.popen` で外部プログラムを実行してもコンソールウィンドウは表示されない
- エラーはステータスバーに表示され、完全な呼び出し履歴は `scripts\error.log` に記録。`log()` は `scripts\zing.log` に書き込む
- 読み込み時に `scripts\.zing\` に LuaLS の定義ファイルと `.luarc.json` を生成：VS Code の Lua 拡張機能で `scripts` フォルダーを開くと補完と説明が使える
- ブレークポイントによるデバッグ：`pwsh tools/install-vscode-ext.ps1` で VS Code の拡張機能をインストールし、VS Code で `scripts` フォルダーを開き、zing を開いたまま F5 でアタッチ。
  ブレークポイント、条件付きブレークポイント、ログポイント、ステップ実行、呼び出し履歴、変数、式の評価に対応し、スクリプトのエラーが起きた場所で止まる

例（`zing.exe` の隣の `scripts\` にコピーし、コマンドパレットで「Lua スクリプトを再読み込み」を実行。メッセージは中国語です）：

- [extract.lua](examples/scripts/extract.lua)：Windows 組み込みの tar.exe で、指定したフォルダーにまとめて展開
- [rename_pattern.lua](examples/scripts/rename_pattern.lua)：Lua のパターンで名前を一括変更（拡張子は維持、名前が重なると番号を付ける）。元に戻せる
- [checksum.lua](examples/scripts/checksum.lua)：SHA-256 を計算して `.sha256` ファイルに書き込む（ファイルが 1 つならクリップボードにもコピー）、または `.sha256` ファイルで検証（certutil、`io.popen`）
- [organize.lua](examples/scripts/organize.lua)：拡張子ごとに「画像」「動画」「文書」などのサブフォルダーへ、または更新日時で「年-月」フォルダーへ移動（`stat()`）
- [folder_view.lua](examples/scripts/folder_view.lua)：イベント関数。写真のフォルダーを自動でサムネイル表示にし、カバー画像をフォルダーのサムネイルにする

関数の完全な説明は [docs/lua.ja.md](docs/lua.ja.md) を参照してください（コードから生成されるので、常にプログラムと一致します）。

テーマ（コマンドパレット）：
- 「現在のテーマを編集」：右側のパネルに配色、フォント、サイズ、外観が並び、変更はすぐに適用される。色は色見本をクリックして選ぶか `#rrggbb` を入力、
  数値はホイールで微調整できる。「新しいテーマとして保存」は組み込みの基のテーマと異なる欄だけを保存。組み込みテーマは上書きできない。「キャンセル」で元に戻す
- 「現在のテーマファイルをテキストエディターで開く」：保存すると自動で適用
- 「テーマをインポート…」「現在のテーマをエクスポート…」：`.zingtheme` ファイル。`.zingtheme` をウィンドウにドラッグしてもインポートできる
- 最後に選んだテーマは記憶される。設定ファイルの `theme` を変更して再読み込みしたときは設定ファイルが優先

テーマファイルは `zing.exe` の隣の `themes\<名前>.toml` に置きます。変更したい欄だけを書けばよく、残りは `style`（compact | fluent | balanced）
と `mode`（dark | light）で選んだ組み込みテーマのものが使われます：

```toml
style = "fluent"
mode = "dark"
[color]
accent = "#4cc2ff"
[metrics]
row_height = 30
[chrome]
address = "path"        # path（フルパス）| breadcrumb（パンくずリスト）
```

## フォルダーのサイズと全ドライブ検索

- **NTFS インデックス サービス（推奨）**：コマンドパレットで「NTFS インデックス サービスを有効にする」を実行します（UAC が表示されます）。zing の更新後、サービスが古いバージョンなら zing の起動時に自動で更新します（同じく UAC で確認。キャンセルすると次回の起動時にもう一度確認します）。
  サービスはローカルの NTFS ドライブごとにマスター ファイル テーブル（MFT）を読んでインデックスを作り、その後は NTFS の変更ジャーナルに従って更新するので、どのフォルダーのサイズもすぐに表示され、
  ファイルの変更にも自動で追従します。全ドライブ検索（`Ctrl+F`）もこのサービスが提供します。
  仕組みは Everything と同じで、ボリュームを読む権限はサービス（`zing-index`、LocalSystem）だけが持ち、`zing.exe` は通常の権限のままです。
  サービスは問い合わせのたびに呼び出し元の権限でそのフォルダーを一覧できるか確認し、検索結果には一覧できるフォルダー内の項目だけが含まれます。
  - インデックスのメモリは 100 万レコードあたり約 47 MB（すべてのファイル名と更新日時を含む）。100 万個の名前の検索は約 10–20 ms
  - 初回のインデックス作成は数秒から数十秒。以後はスナップショットと変更ジャーナルから再開し、スキャンし直す必要はない
  - サイズは論理サイズ。ハードリンクのファイルは 1 回だけ数える（エクスプローラーのプロパティは重複して数えるため、`C:\Windows` では数 GB の差が出る）。隠しファイルやシステムファイルも含む
  - サービスの実行ファイルは `%ProgramFiles%\zing-explore` にインストールされ、スナップショットとログはサービス アカウントの
    `C:\Windows\System32\config\systemprofile\AppData\Local\zing-explore` にある
  - コマンドライン：`zing-index --status`、`--install`、`--uninstall`。管理者として
    `zing-index --scan C: --verify C:\Users` を実行すると、MFT の読み取り時間を測ってフォルダーごとのスキャンと比較できる
- **インデックスがないとき**（サービスが無効、NTFS 以外やネットワークのドライブ）：`[folder_sizes] auto = true`（既定）なら、ローカルの固定ドライブのフォルダーに入ると
  バックグラウンドの優先度でフォルダーごとに計算します。`Ctrl+Shift+S` で選択した（またはすべての）フォルダーを計算します。結果は `%LOCALAPPDATA%\zing-explore\folder-sizes.tsv` にキャッシュされます。

### 全ドライブ検索の構文

複数の語は空白で区切り、すべてが一致する必要があります。空白を含む語は `"…"` で囲み、`!` で始めると除外です。大文字小文字は区別しません（é、Σ、全角英字なども含む）。

| 書き方 | 意味 |
| --- | --- |
| `報告 2024` | 名前に「報告」と「2024」の両方を含む |
| `*.jpg`、`img_????.png` | ワイルドカードで名前全体を照合（`?` は 1 文字） |
| `src\ main`、`c:\users\*\デスクトップ\*` | `\` を含む語はフルパスと照合 |
| `!node_modules\`、`!*.tmp` | 除外 |
| `ext:jpg;png` | 拡張子（ファイルのみ） |
| `size:>10mb`、`size:<=1k`、`size:1mb..1gb` | サイズ（フォルダーはフォルダー全体のサイズ） |
| `dm:today`、`dm:yesterday`、`dm:7d`、`dm:2024-05`、`dm:>2024-05-01`、`dm:2024-01..2024-03` | 更新日時 |
| `file:`、`folder:` | ファイル／フォルダーのみ |
| `sort:size`、`sort:date`、`sort:name`、`sort:path`、`sort:ext`（`-asc`／`-desc` を付けられる） | 並べ替え。サイズと日付の既定は大きい順。名前、パス、拡張子は自然順（`file2` が `file10` より前） |

検索パネルで `Ctrl+1`–`Ctrl+5` を押すと名前・パス・拡張子・サイズ・日付で並べ替え（クエリの `sort:` を書き換える。もう一度押すと逆順）、`Ctrl+0` で並べ替えを解除します。
入力欄の右に現在の並べ替えと結果の件数が表示されます。

並べ替えを指定しないと、ドライブごとに作成順で見つかった順に表示されます（最速）。並べ替えるときはすべてのドライブを照合し終える必要があり、最長約 3 秒で、それを超えると見つかった分だけを並べ替えます（「500+ 件」と表示）。
フォルダーの更新日時は、そのフォルダー自身のレコードが変わったときだけ更新されます（中の項目を追加・削除しても更新されるとは限りません）。

## 翻訳

画面の文字は繁体字中国語を原文（キー）とし、翻訳は `crates/zing-core/i18n/en.toml`、`ja.toml`（`"原文" = "翻訳"`）にあります。
`cargo test -p zing-core i18n` で、すべての原文に翻訳があり引数の名前が一致しているかを確認します。`ZING_I18N_MISSING=1` を付けると不足している項目を一覧表示します。
Lua API の文書（`docs/lua*.md`）は `scriptapi.rs` と同じ翻訳から生成されます。
